# Тюнер 372505

Страница для одной прошивки: Audi A4 BFB, ЭБУ `8E0909518AQ`, софт `372505`.

Закидываешь полный дамп 1 МБ. Страница читает LDRXN, смесь, попкорн и idle-lope, предлагает безопасные крутилки и отдаёт новый `.bin` с пересчитанной контрольной суммой (me7sum).

Чужой софт не открывается. Нейросеть байты сама не переписывает: двигаются только эти карты.

```
python3 app.py
```

Открыть http://127.0.0.1:8765
